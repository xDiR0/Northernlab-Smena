# NORTHERNLAB: СМЕНА НЕ ОКОНЧЕНА

Небольшая автономная 2D-игра для Unity **6000.0.62f1**. Семь смен по 225 секунд (26 минут без меню), восемь помещений, распределение мощности, перенос предметов, ремонт, мини-игры предохранителя и настройки радио, существо, улучшения и эвакуация. Интерфейс на русском. Интернет во время игры не нужен.

## Запуск

1. Установить Unity 6000.0.62f1 через Unity Hub. Для Windows-сборки добавить Windows Build Support; для Linux — Linux Build Support.
2. Открыть эту папку как проект. Дождаться импорта включённых ресурсов и стандартных пакетов Unity.
3. Открыть `Assets/Scenes/Station.unity`, нажать Play. Никакие ссылки вручную назначать не нужно.
4. Главное меню → «Новая игра». Контрольная точка создаётся в начале кампании и между сменами.

Сцена содержит контроллер и 17 редактируемых объектов устройств. Их координаты, тип, надпись и смена открытия доступны в Inspector; шаблоны находятся в `Assets/Prefabs`. Графическое оформление станции создаётся при запуске в `StationView`; декорации можно менять в этом файле. Это упрощённый способ авторинга: комнаты и HUD пока не редактируются как готовая визуальная иерархия в сцене. Экономика, продолжительность, записи и задания — `Assets/Resources/StationBalance.asset`.

## Управление

- ЛКМ по подписи или оборудованию: подойти и взаимодействовать. Другой этаж — автоматический маршрут через центральный лифт.
- В руках один предмет. Кнопка «В руках … ↓» освобождает руки: канистра/предохранитель кладутся на пол, инструмент остаётся доступен на верстаке.
- Колесо: приближение; средняя кнопка + движение: камера; Home: общий вид.
- Escape: закрыть панель / пауза. Ремонт: удерживать кнопку в панели. Время идёт при открытых приборах, останавливается в меню и паузе.
- Фальшфейер: нажать на красный сигнальный предмет на нижней площадке; запас указан реакцией диспетчера. При предупреждении безопаснее заранее закрыть заслонку у верхнего лифта.

## Прохождение

В начале принесите канистру к генератору. Доставьте F-3 из мастерской к щиту и выберите 3 А. Возьмите инструмент; для каждого этапа ремонта радио нужно 2 запчасти. Всего три этапа. Ящики пополняются к следующей смене; запасы топлива и фальшфейеров довозятся между сменами. Эти уступки и ограничение холода в первой смене защищают обучение от тупиков. Обязательные предметы можно снова подобрать.

Базовая мощность 5, потребности: тепло 2, свет 1, биосдерживание 3, радио 2. При превышении мощности все потребители отключаются. Выберите нужные рубильники на физическом щите. Форсаж даёт 8, но греет генератор и привлекает образец. На третьей смене отопление требует 3. Инструмент нужен и для аварий генератора. После сирены вернитесь к обогревателю: есть дополнительная минута. В отчёте улучшения стоят по 3 детали; покупать все не требуется.

Перед финалом восстановите радио до 3/3, заправьте генератор, закройте заслонку. Тепло + радио укладываются в 5 без улучшений. Настройте частоту по максимуму сигнала, зафиксируйте её, оставьте панель радио открытой для передачи. Нужно 85 секунд питания; прерывание не сбрасывает SOS. После передачи дождитесь конца седьмой смены. Если сигнал не завершён, финальная смена продлевается. Альтернатива — форсаж с контролем нагрева или аккумулятор для дополнительной мощности.

## Сохранение и сборка

Сохранение: `Application.persistentDataPath/northernlab-save.json`. «Продолжить» и повтор после поражения возвращают к началу сохранённой смены. Настройки звука/окна — PlayerPrefs. Новая игра заменяет контрольную точку.

Меню редактора `NorthernLab → Build Windows x64` или `Build Linux x64`. Результаты в `Builds/Windows` / `Builds/Linux`. Для автоматизации:

```sh
Unity -batchmode -quit -projectPath /path/to/NorthernLab -executeMethod NorthernLab.BuildGame.Windows -logFile build.log
Unity -batchmode -quit -projectPath /path/to/NorthernLab -runTests -testPlatform EditMode -testResults results.xml -logFile tests.log
```

## Статус проверки

В среде подготовки **нет Unity Editor**. Импорт проекта, C#-компиляция с Unity API, Play Mode, звук в плеере, сохранение на диске плеера и Windows/Linux-сборки **не проверены**. Исполняемая сборка не приложена. Нельзя считать проект подтверждённым релизом до проверки в редакторе.

Выполнен `Tools/validate.py`: синтаксический разбор C#, проверка GUID-ссылок сцены/префабов/конфигурации, числа смен и объектов, наличия шрифта/звуков и базового бюджета финала. Это не запуск игры. В `Assets/Tests/Editor` включены восемь Edit Mode тестов: перегрузка, пауза SOS, условие победы без улучшений, маршрут через лифт, переохлаждение, прощение первой смены, схема сохранения и отчёт шести смен. Они также ещё не запускались в Unity.

Рекомендуемая ручная приёмка: новая игра → канистра/генератор → предохранитель → щит → переход вниз/вверх → ремонт радио → отчёт/улучшение → перезапуск/продолжить → предупреждение/заслонка/фальшфейер → SOS/победа → повтор после поражения → обе целевые сборки.
